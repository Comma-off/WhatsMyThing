# WhatsMyThing
A website to acknowledge your device info, browser info and more.

# Why is there a README.md?
For no reason.

# Is there any chance to leak my info?
Nope. At least, not unless you explicitly screenshot the information on the website and/or send it somewhere. Anything that happens after that is your responsibility.
